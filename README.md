Trabajo final. 
En este trabajo final se implementa un sistema de gestión de catalogo de recursos y préstamos a usuarios. maneja libors fisicos, revistas y recursos digitales, compartiendo atributos, pero cada uno se comporta de manera distinta.
Libro: autor e ISBN.
Revista: número de edición y editorial.
Recurso digital: URL de acceso. Solo puede consultarse en sala, no se presta.
Todo se puede prestar (lo fisico), excepto si es de antes de 1923.
Decisiones de diseño:
Usar paquetes para distribuir bien, clases, excepciones, funcionamiento de estas clases, catalogo, y el main (como en el taller).
